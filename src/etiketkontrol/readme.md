🚀 Özellikler

Görsel Doğrulama: YOLO .txt etiketlerini (0-1 arası normalize edilmiş) gerçek piksel koordinatlarına çevirip resim üzerine çizer.



Hızlı Gezinme: Klavye tuşları ile kareler arasında senkronize geçiş sağlar.



Hata Tespiti: Etiketi eksik olan kareleri tespit ederek ekranda uyarı verir.



ÇALIŞABİLMESİ İÇİN KOD İCİNDEKİ DOSYA YOLLARININ (fotoğrafların ve txt) olduğu dosya yollarını koddaki ilgili yolları yazın 

🛠️ Kurulum

Gerekli kütüphaneleri yüklemek için terminalde proje dizinine gidin ve şu komutu çalıştırın:



Bash

pip install -r requirements.txt

⚙️ Kullanım

Gerekli dosya yollarını (images ve labels) düzenledikten sonra terminalden scripti çalıştırın:



Bash

python goruntule.py

🎮 Kontroller (Kısayollar)

\[D] veya \[Sağ Yön Tuşu] : Sonraki Kare



\[A] veya \[Sol Yön Tuşu] : Önceki Kare



\[Q] veya \[ESC]          : Çıkış / Kapat
